# 测试约定

初始仓库只有工作流，没有运行代码或自动测试。检查文档不等于完成模型或实机验收。

添加代码时再添加对应测试，优先覆盖：

1. EVA → 模型：字段、左右顺序、单位、夹爪、图像颜色/布局。
2. 模型 → EVA：动作维度、有限值、归一化与反变换只做一次。
3. 数据：时间戳、缺帧、command/state 区别、按 episode 划分不重叠。
4. 控制接口：回合重置、超时、旧动作拒绝、模式切换清缓存、控制权互斥。
5. 统计：失败/干预/异常不被隐去，中断不生成完整成功率。

默认测试使用小型脱敏样本、假模型和不会发送实机指令的接收端。测试导入模块也不得自动初始化硬件。

GPU 模型加载/推理是单独的集成验证；实机检查由现场流程执行，结果写报告。不要放进普通测试自动发现或 GitHub CI。

首次实现代码时选择最少依赖的测试入口，将实际命令写在这里和 README；当前没有可宣称通过的测试套件。无需为了填满目录给文档写测试。
